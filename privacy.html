跑步教練 · 更新日期：2026年11月6日

跑步教練是個人興趣製作的網頁應用（PWA），用來記錄跑步、估計體能並安排課表。這不是商業服務，不向使用者收費，也沒有帳號系統。

目前存在你瀏覽器裡的資料

你在這個網站輸入或匯入的內容，只寫入你自己的瀏覽器 localStorage，不會上傳到本站的伺服器。本站架在 GitHub Pages，只提供靜態檔案。這些資料包括：

  • 手動跑步紀錄：日期、距離、時間、平均心率、備註。
  • 你選擇上傳的 Garmin 匯出檔（Activities.csv、GPX 或 FIT）以及在本機解析後的活動。
  • 比賽成績、訓練目標，以及由此算出的體能估計（例如 VDOT、預測完賽時間）與課表。

Claude 教練（已啟用）

「教練」頁的問答會把你的問題，以及回答所需的活動上下文，以 HTTPS POST 送到 Cloudflare Worker（run-app-coach.helloajchu.workers.dev/chat）。上下文包括近期跑步、比賽成績、目標、課表摘要，以及 VDOT 與預測。這些內容只用來產生教練回覆。

  • Claude 的 API 金鑰只存在 Worker 的秘密設定，不會出現在這個網站，也不會存在你的瀏覽器。
  • 這個頁面不要求你填寫模型金鑰。預設即可使用。
  • 若你在進階設定改了後端網址，問題與同樣的上下文會改送到該網址。

Garmin 連線

目前尚未啟用 Garmin OAuth。若日後啟用，授權權杖會放在同一個 Cloudflare Worker，不會寫進這個靜態網站的原始碼。相關活動資料只會為了提供教練功能而傳送。

我們不出售資料

我們不出售個人資料，也不把你的跑步紀錄用於廣告或提供給資料仲介。

你的控制

可在 App「教練」頁清除全部資料，或用瀏覽器清除此網站的網站資料。清除後，存在這台裝置上的紀錄會一併刪除。
